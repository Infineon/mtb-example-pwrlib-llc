Dead time LUT modulation
LLC Configuration

General Description

The primary bridge driver dead time can be (optionally) controlled by the T_dt look-up table.


The dead time (in LUT mode) is modulated based of switching frequency and conductance, similarly to the Synchronous rectifier timing.
The dead time value is expressed naturally in seconds, e.g. 50.0E-9f means 50 ns.
It is not recommended to set the dead time less than 20ns for the KIT_PSC3_LLC1 board.

Note
the params.llc.dt.method is set to DT_Perc (percentage) by default - this setting should be changed to DT_LUT to make the system work with T_dt table.

To perform fine dead time tuning, the simplest way is to observe the primary bridge voltage (e.g. TP503 or TP513 to GND_PP on the KIT_PSC3_LLC1) by the oscilloscope:

  • The smooth slope without any creases with duration ~40ns and no significant ringing at the end means 'soft switching':
  • The noticeable bending at the slope line, reduced duration, and trailing ringing means 'hard switching':
    The T_dt can be precisely adjusted to achieve the minimal dead time with soft switching in whole the working range (frequency vs load) for the particular board.
